# Önéletrajz

Egyszerű, nyomtatható HTML/CSS önéletrajz projekt, amely GitHub Pages-en is könnyen publikálható.

## Tartalom
- `index.html` — a CV oldala
- `styles.css` — A4 nyomtatási stílusokkal és kékes megjelenéssel

## Telepítés és publikálás
1. Helyezd a fájlokat a repository gyökérkönyvtárába.
2. A GitHub Pages beállításánál válaszd a `main` (vagy `master`) branch `root` mappáját.
3. Nyisd meg a GitHub Pages URL-t, és ellenőrizd a weboldalt.

## Használat
- Nyomtatáshoz a böngésző `Fájl > Nyomtatás` menüjéből válassz A4 méretet.
- PDF mentéshez a böngésző `Mentés PDF-ként` opcióját használd.
